# KDV Çapraz Kontrol — yayın deposu

Bu depo **yalnızca yayın (release) dosyalarını** barındırır. Kaynak kod burada
yoktur.

- Ürün sitesi: https://ardaekiz0.github.io/kdv-indir/
- Güncel sürüm: [Releases](../../releases/latest) → `KDV-Capraz-Kontrol-kurulum.exe`
  veya `KDV-Capraz-Kontrol-portable.zip`
- Doğrulama: her sürümle birlikte `SHA256SUMS.txt` ve Ed25519 imzası
  (`SHA256SUMS.txt.sig`), ayrıca yazılım bileşen listesi (`SBOM.json`) yayınlanır.

Bu depo, kurulu eski sürümlerin otomatik güncelleme denetimini yaptığı adrestir
(`ArdaEkiz0/kdv-capraz-kontrol`). Sürüm yayınlandığında buraya da aynı dosyalar
yüklenir.
